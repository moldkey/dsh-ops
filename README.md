# dsh-plugin-catalog (branch: catalog)

deepseekbase 的 DeepSeek Harness 插件市场索引（format 1），可直接作为 DSH 索引源。

## 用法
DSH → 插件 → 发现（Discover）→ 索引源（Index sources）→ 添加：

https://cdn.jsdelivr.net/gh/moldkey/dsh-ops@catalog/index.json

备用（源站）：
https://deepseekbase.com/market/index.json

每日自动更新。数据来自 deepseekbase.com 插件市场（8,000+ 插件，带沙箱安装判定）。
